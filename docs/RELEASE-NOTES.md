**Mac 安装与首次打开**：先在“苹果菜单 → 关于本机”确认芯片是 Apple M 系列。打开下载的 DMG，把 LatexStudio 拖到“应用程序”。因为未经 Apple 公证，第一次双击会被系统拦截：先点“完成”，再打开“系统设置 → 隐私与安全性”，在页面下方找到 LatexStudio 的提示并点“仍要打开”。之后可正常双击打开。

<summary>版本说明与开发者资料</summary>

- 首页项目列表现在直接显示每篇论文的云端状态：登录后会列出账号下**尚未下载到这台电脑**的私有论文（标为“云端”），点“下载到本地”并选择空文件夹即可取回；本机论文标明“可同步”（已关联云端）或“未上传到云端”，列表上方汇总本机、已关联和仅在云端的数量。只读取项目名称等公开信息；下载和同步仍然只在你明确点击后发生，登录或打开首页不会自动下载、上传或同步。
- Mac 版改为 **DMG 安装包**（Apple 芯片）：打开后把 LatexStudio 拖到“应用程序”。不再提供应用 ZIP，也不提供 Intel 芯片版；仍未经 Apple 公证，首次打开步骤见上方说明。
- 修复从“分享”或“加入项目”窗口发起登录后又取消时，之后在别处登录会误弹出该窗口的问题。
- 新增 LaTeX 源码 ↔ PDF **单词级双向双击跳转（SyncTeX）与醒目高亮**：`pdflatex` / `xelatex` 编译自动生成受限读取的 `.synctex.gz`（剥离构建临时目录，仅映射合法项目相对路径）；双击源码中单词可在 PDF 精准高亮对应词位置（高对比琥珀金定位框持续 3.5 秒），双击 PDF 中单词或位置可准确跳回并打开对应 `.tex` 文件、选中目标词并亮金色高亮提示 4.5 秒（不依赖外部工具）。
- 优化 PDF 预览交互模式：**按住 `Ctrl / ⌘` 键**时启用滚轮缩放与左键抓手拖拽平移；**未按 `Ctrl`** 时支持直接拖拽划词复制（纯文本覆盖层，不启用 PDF 脚本、批注或外链）、普通滚动与双击跳转。
- 统一源码编辑器工具栏 5 枚图标（撤销、重做、加粗、斜体、查找）为等尺寸线性 SVG 图形，消除原有字体/符号尺寸与粗细不均的问题。
- 深化后台与渲染性能及内存优化：主进程更新模块改按首次真实检查延迟加载，目录遍历与指纹采集复用单次 `lstat`，Git 历史与本地版本检验引入单次只读缓存与 4 路有界并发，文件树排序复用 `Intl.Collator`，章节大纲批量跳过纯文本，并在云端列表刷新时及时释放旧行监听器。
- 全面升级客户端视觉风格：采用冰岩灰与深空蓝（Cobalt Blue）主色调，配合薄荷绿状态徽标，重构首页项目卡片（含本地 / GitHub / 关联异常语义状态标签）、双栏工作台工具栏、修改历史、登录/设置浮层与紧凑滚动条。
- 简化“关于与开源许可”弹窗说明，明确 LatexStudio 为开源且永久免费软件，同时保留完整的 GNU AGPL v3 与第三方组件许可声明；统一使用跨平台无版权顾虑的系统默认无衬线与等宽字体栈，并移除开发者 PAT 调试区多余的内部验收提示文字。
- 修复编译后 PDF 预览无法缩放与闪烁问题：支持 `Ctrl / ⌘ + 滚轮` 缩放，缩放与翻页按钮不再被全局锁阻塞，重新编译后保留当前缩放比例，切换比例时通过原地平滑缩放消除白屏闪烁；并将“停止编译”按钮重设计为红色圆角胶囊样式，将右下角提示浮层移至底部避免遮挡工具栏。
- 优化源码编辑与后台扫描性能：避免章节大纲、文件树、主文件下拉列表与多语言 DOM 在内容未变化时重复重建；差异对比算法先裁剪公共前后缀再计算变更；本地项目扫描采用分批并发读取元数据，提升大项目响应速度。
- 去掉静态“文件树”“文件大纲”标题前误导性的文字箭头；标题本来不是折叠按钮，真实目录的展开／收起与可访问性保持不变，中英韩均使用纯标题。
- 修复编译工具栏“选项”“日志”悬停时浅底浅字问题，统一深色悬停／键盘焦点／展开状态；下拉箭头改为文字右侧居中的单一图形，展开方向同步变化，中英韩均不再携带下坠的文字箭头。选项浮层限制在 PDF 面板内，窄窗口也可完整操作。
- “分享”现在直接显示可复制项目链接；首页和账号菜单新增“加入项目”。接收者可打开 LatexStudio 项目链接或粘贴 GitHub HTTPS 地址，明确确认后选择空文件夹下载，打开独立本地副本并向同一个原仓库同步，不自动新建仓库或上传论文。
- 私有权限、邀请接受与 App 安装范围仍独立验证，链接不授予访问权；新增受控启动／第二实例／macOS 链接接收，只预填不自动执行。协议关联仅用于打包安装版，开发／便携入口可手动粘贴。
- 已确认接受邀请后若安装范围查询暂时失败，不再把已接受操作误报为失败或引导重复接受；真正的取消、会话、权限及 HTTP 清理否决仍保留。PDF 预览清理失败也不再阻断已提交工作区的界面接收。
- 新增完整软件界面的简体中文、English、한국어：项目首页、编辑器与搜索、PDF 控件、修改历史、账号、同步、组件、更新、确认弹窗及软件自身固定系统提示均随语言选择切换；账号菜单中选择语言，设置安全保存并跨启动保留。
- 切换语言不翻译或改写论文、源码、文件名、账户/仓库标识及编译器原始日志，也不触发登录、同步或编译；保留正在编辑的草稿、选择与撤销历史。
- GitHub 设备登录改为安全自动续期：访问与续期凭据仅在主进程使用并由操作系统加密保存，重启时重新验证身份；主动退出会清除本机登录。临时断网不删除续期授权，GitHub 撤销授权或续期授权失效仍须重新登录。不使用 App Secret、不关闭 GitHub 的令牌有效期。
- 续期成功后若身份校验暂时断网，30 秒后自动重试校验；不等待下一轮访问令牌到期，也不重复消耗已轮换的续期凭据。
- 从旧版升级后，因旧记录没有续期凭据，需要退出并重新登录一次以取得完整授权；之后不再因短期访问令牌到期反复手动登录。系统安全存储不可用时仍仅本次运行有效，不以明文回退。
- 右上角使用当前登录账号的 GitHub 头像；从固定 GitHub 头像域名按账号ID加载，不发送登录令牌或页面来源。离线、加载失败时显示首字母占位，退出／切换账号立即清理旧头像，不影响写作或同步。
- 修复同步的两处 HTTP 生命周期缺陷：取消时先正确释放响应流；Git 协议响应完整收束后再交给 Git 解析器，避免后续请求误报并发与清理失败。仍保留取消、限时、累计流量上限和真实清理失败保护。
- 已通过真实 GitHub App 私有测试仓库验证首次上传、独立空目录下载、两份副本双向修改、取消后再次同步。仅使用隔离测试文章，不包含个人论文；未冒充另一个人的账号完成邀请测试。
- 同步按钮先保存当前草稿再同步，不再重复弹确认；未登录或未关联时可直接进入所需设置。成功同步后清除已解决的同步错误，其他未解决错误仍保留。
- 参照 Overleaf 官方 History 文档与界面，修改历史改为独立只读模式：左侧文件、中央带行号的源码比较、右侧版本时间线。新增与删除用绿/红色标出，可跳转修改位置、选择同文件的较早版本比较，并返回原编辑草稿。初始记录不把全文标成新增；当前仅回退所选文件，不伪装成整个项目快照。
- 云端操作失败详情完整保留在项目设置中，支持多行、滚动和复制；普通提示也不再以单行省略号截断。不会自动重试建库，403 的具体拒绝原因仍需按实际授权和账号状态核实。
- PDF 改为连续纵向滚动，支持 50%–200% 缩放，并随预览区域宽度重新排版；只渲染附近页面，限制位图资源。
- 源码与 PDF 之间支持拖动分割线、方向键调整和双击复位；停止编译与选项增加清晰标识。
- 创建私有仓库时区分权限拒绝、名称冲突等固定错误；已确认创建成功但后续访问检查未完成时，不再误报创建失败或引导重复创建。真实账号能否创建仍受 GitHub App 权限及账号策略约束。
- 独立项目首页、论文编辑工作台、章节大纲；编辑模式保留源码与 PDF 的空间，历史不再挤在 PDF 右侧。
- 当前论文同步、可开关日志，以及操作系统加密的有效登录会话。
- 更新前请保存草稿并正常关闭旧软件，不要删除应用数据或论文目录。
- 当前未签名版本只提示手动下载安装，不在编辑时强制更新或绕过系统校验。
- Assets 中的其他文件用于更新元数据、校验、便携测试或对应源码；普通使用者无需下载它们。SHA256SUMS 仅用于完整性核对，不等于受信代码签名。
- 对应源码及第三方许可随版本保留，源代码和原生依赖的再分发义务不因简化下载入口而取消。
