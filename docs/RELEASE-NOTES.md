<summary>版本说明与开发者资料</summary>

- **PDF 里的高亮框更准**：PDF 查找的命中、评论高亮、从源码跳到 PDF 时的词框，原来按“一行里每个字符一样宽”取位置，窄字母（i、l、I）多的行里会偏一个字母以上。现在用 PDF 自带字体逐字符量宽度，并按 TeX 的排法处理行内空格、句末加宽的空格和 fi / ffi 等连字；某一页还没画出来时先用相近字体估算，画出来后自动校正，不会跳转或改变当前选中的一处。（同一台 Windows 电脑上自编的三份两栏样例，每份 46 处命中：框住的字母数不对的由 20–24 处降为 0，边缘最大偏差由约 13 pt 降到 1.3–1.8 pt。）仍有局限：只含位图字体（Type 3）的 PDF 只能估算，可能偏半个到一个字母；字偶间距量不到，个别行仍有约 1 pt 误差。
- **源码查找重做**：查找条移到源码上方，字号和控件放大；输入时直接跳到光标后最近的一处并显示“第几处 / 共几处”，没有结果时输入框变红；提供区分大小写、全字匹配、正则三个开关，替换行默认收起。修复带反斜杠的命令（如 `\newcommand`、`\textbf`、`\ref`）此前搜不到的问题。点工具栏的查找按钮后，焦点留在查找框里。
- **新增 PDF 内查找**：PDF 工具栏新增放大镜按钮，在 PDF 页面上点过之后按 `Ctrl / ⌘ + F` 也能打开。所有命中标黄、当前一处标橙，`Enter` / `Shift+Enter` 前后跳转，`Esc` 关闭；重新编译后按原来的词自动重搜。匹配不区分大小写，忽略标点、空格、换行和行尾断词，因此跨行的词也能搜到，但只有符号的查询（如单独一个 `=`）搜不到。只搜页面上的文字，不读取 PDF 里的链接、批注或脚本。
- **性能**（括号内为同一台 Windows 电脑、自建样本上的前后对比，不代表每台电脑、每篇论文的实际耗时）：
  - 打开论文后每半秒一次的文件变化检查，每个文件所需的系统调用由“每级目录各两次”降为固定两次（1000 个文件、三级目录：约 1.5 秒 → 0.3 秒）；两次检查之间的间隔不再固定，至少是上一次耗时的两倍；窗口最小化或隐藏时改为每 5 秒一次，恢复窗口时立即检查。
  - 首页项目列表的“最后修改”不再对每个文件重复查两遍（500 个文件的论文：约 2.4 秒 → 0.2 秒；20 篇同时：约 9 秒 → 0.8 秒），并改为一次最多读 4 篇，避免占满磁盘线程。
  - 保存文件时读取本地修改历史更快（已有 150 个版本：一次保存约 0.30 秒 → 0.15 秒）。每个历史文件仍逐一读取并校验内容，只是历史目录本身的检查由“每个文件一次”改为“每批前后各一次”。
  - 同步前的检查更快：不再为每个文件单独询问 Git 的忽略规则（3000 个文件：约 3.0 秒 → 不到 0.1 秒，每次同步至少做两遍）；上传前检查历史时，同一次检查中没有变化的文件夹不再重复读取（仍计入单次提交的文件数上限）（200 个提交：约 1.4 秒 → 0.4 秒）；检查 `.git` 目录时的元数据读取改为分批进行（2 万个文件：约 1.0 秒 → 0.3 秒）。链接、特殊文件、不安全文件名和数量上限的检查都保留。
  - 输入时不再每按一键就重新分析一次章节大纲，改为停顿约 0.2 秒后更新（1MB 的源文件：每次按键约 3 毫秒 → 0.7 毫秒；在标题上方换行约 8 毫秒 → 1 毫秒）。打开或重新载入文件时大纲仍立即更新。
- 源码编辑器改用与 Overleaf 默认设置相同的等宽字体：依次尝试 Monaco、Menlo、Ubuntu Mono、Consolas，都是系统已有的字体，软件不另外打包字体文件。Windows 上一般显示为 Consolas（装了 Ubuntu Mono 的电脑显示 Ubuntu Mono），Mac 上一般显示为 Monaco。中文注释改用微软雅黑（Mac 上为苹方），韩文用 Malgun Gothic（Mac 上为 Apple SD Gothic Neo）；Mac 上的显示效果尚未实测。此前在中文 Windows 上，源码的英文和中文都会显示成新宋体。字号和行高不变。
- 新增 **PDF 评论**：阅读 PDF 时不按 Ctrl 拖选一个单词或一段话（需在同一页内），点旁边的“添加评论”即可留言；PDF 工具栏的“评论”按钮打开评论栏，数字是未解决条数。未解决的评论在 PDF 上显示红色高亮，点高亮会打开对应评论。改完后点“标记为已修改”，评论变成绿色，只保留在右侧评论栏，原文上不再标记；“重新打开”可以撤销，任何合作者都可以标记或撤销。点评论卡片会跳到原文并临时高亮。可以回复别人的评论（一层）。重新编译后评论会按原文重新找回位置；原文被改写、找不到时显示“位置已失效”和原来的文件与行号，不猜位置，也不丢评论。
- 评论保存在论文文件夹的 `.latexstudio/comments/` 中，每台设备一个只追加的文件，随“同步”提交到当前私有仓库，合作者同步后就能看到，不是实时推送。这个文件夹不会出现在文件树、编译和修改历史里。同步新增唯一一种自动合并：两边都有新提交时，如果其中一方自上次同步以来只新增了评论，软件会自动合并后上传（不强推）；其他分歧仍和以前一样停下来等人工处理。署名用登录的 GitHub 账号，离线时用这台电脑最近一次登录过的账号，从没登录过的电脑显示“未登录用户”和设备号；署名由软件填写，不是防篡改签名。合作者需要都升级到 0.4.11：旧版看不到评论，会把 `.latexstudio` 文件夹当成普通文件显示，也不会自动合并。Mac 版目前不能编译，因此无法在 PDF 上选字评论。
- PDF 工具栏新增 **“下载 PDF”**：把最近一次编译成功的 PDF 另存到本地，默认放在“下载”文件夹，文件名取主文件名。编译后源码又改过时，会提示保存的是上一次编译的结果，不会为了下载自动重新编译。本次打开软件后当前论文还没有编译成功过时，按钮不可用；Mac 版不能编译，按钮也不可用。
- 首页本地论文一行的“×”改为文字按钮“移出”，与云端论文的“下载”按钮同样大小。功能不变：只把这篇论文从首页列表移出，不删除硬盘上的文件夹、论文文件或历史记录，之后可用“打开本地论文”重新添加。
- 首页项目列表的列现在对齐：表头与每一行使用同一套列宽，“存储位置”“最后修改”及新增的“操作”列居中显示；云端论文的“下载”按钮移到“操作”列（与本地论文的“×”同列），不再出现在“最后修改”下面，云端论文未下载前的修改时间显示为“—”。
- **云端关联需在本机确认一次**：论文文件夹里记录的“关联到哪个云端仓库”会随文件夹一起被复制或转交，因此不再单凭它决定上传目标。在这台电脑上通过 LatexStudio 关联、创建或下载的项目自动视为已确认；其他情况（例如文件夹来自他人或另一台设备，或是从旧版升级前关联的论文）会在第一次同步、开启自动同步或邀请合作者之前弹出一次确认，写明仓库、文件夹和分支；确认记录保存在本机，之后一般不再询问。取消则不向 GitHub 发送任何内容；后台自动同步不会弹窗，遇到未确认的关联会停用并提示先手动同步一次。
- **登录方式变更（需要重新登录一次）**：GitHub 登录改用 OAuth App 的设备登录，登录时一次性授权账号下仓库的读写（GitHub 的 `repo` 权限），不再需要为每个仓库单独安装或授权 GitHub App；登录后首页直接列出账号下的私有论文项目。授权范围比旧版更大，但软件仍只读写你明确创建、关联、下载或同步的那个私有项目，不会自动访问其他仓库。登录会一直保持到你退出：软件每隔数小时以及每次启动时向 GitHub 重新核对账号，核对不通过就结束登录并清除本机凭据。凭据只保存在本机操作系统加密存储中；退出登录只清除本机凭据，如需撤销授权，请到 GitHub 的 Settings → Applications → Authorized OAuth Apps 中移除。
- 首页项目列表现在直接显示每篇论文的云端状态：登录后会列出账号下**尚未下载到这台电脑**的私有论文（标为“云端”），点“下载到本地”并选择空文件夹即可取回；本机论文标明“可同步”（已关联云端）或“未上传到云端”，列表上方汇总本机、已关联和仅在云端的数量。只读取项目名称等公开信息；下载和同步仍然只在你明确点击后发生，登录或打开首页不会自动下载、上传或同步。
- Mac 版改为 **DMG 安装包**（Apple 芯片）：打开后把 LatexStudio 拖到“应用程序”。不再提供应用 ZIP，也不提供 Intel 芯片版；仍未经 Apple 公证，首次打开步骤见上方说明。
- 修复从“分享”或“加入项目”窗口发起登录后又取消时，之后在别处登录会误弹出该窗口的问题。
- 新增 LaTeX 源码 ↔ PDF **单词级双向双击跳转（SyncTeX）与醒目高亮**：`pdflatex` / `xelatex` 编译自动生成受限读取的 `.synctex.gz`（剥离构建临时目录，仅映射合法项目相对路径）；双击源码中单词可在 PDF 精准高亮对应词位置（高对比琥珀金定位框持续 3.5 秒），双击 PDF 中单词或位置可准确跳回并打开对应 `.tex` 文件、选中目标词并亮金色高亮提示 4.5 秒（不依赖外部工具）。
- 优化 PDF 预览交互模式：**按住 `Ctrl / ⌘` 键**时启用滚轮缩放与左键抓手拖拽平移；**未按 `Ctrl`** 时支持直接拖拽划词复制（纯文本覆盖层，不启用 PDF 脚本、批注或外链）、普通滚动与双击跳转。
- 统一源码编辑器工具栏 5 枚图标（撤销、重做、加粗、斜体、查找）为等尺寸线性 SVG 图形，消除原有字体/符号尺寸与粗细不均的问题。
- 深化后台与渲染性能及内存优化：主进程更新模块改按首次真实检查延迟加载，目录遍历与指纹采集复用单次 `lstat`，Git 历史与本地版本检验引入单次只读缓存与 4 路有界并发，文件树排序复用 `Intl.Collator`，章节大纲批量跳过纯文本，并在云端列表刷新时及时释放旧行监听器。
- 全面升级客户端视觉风格：采用冰岩灰与深空蓝（Cobalt Blue）主色调，配合薄荷绿状态徽标，重构首页项目卡片（含本地 / GitHub / 关联异常语义状态标签）、双栏工作台工具栏、修改历史、登录/设置浮层与紧凑滚动条。
- 简化“关于与开源许可”弹窗说明，明确 LatexStudio 为开源且永久免费软件，同时保留完整的 GNU AGPL v3 与第三方组件许可声明；统一使用跨平台无版权顾虑的系统默认无衬线与等宽字体栈，并移除开发者 PAT 调试区多余的内部验收提示文字。
- 修复编译后 PDF 预览无法缩放与闪烁问题：支持 `Ctrl / ⌘ + 滚轮` 缩放，缩放与翻页按钮不再被全局锁阻塞，重新编译后保留当前缩放比例，切换比例时通过原地平滑缩放消除白屏闪烁；并将“停止编译”按钮重设计为红色圆角胶囊样式，将右下角提示浮层移至底部避免遮挡工具栏。
- 优化源码编辑与后台扫描性能：避免章节大纲、文件树、主文件下拉列表与多语言 DOM 在内容未变化时重复重建；差异对比算法先裁剪公共前后缀再计算变更；本地项目扫描采用分批并发读取元数据，提升大项目响应速度。
- 去掉静态“文件树”“文件大纲”标题前误导性的文字箭头；标题本来不是折叠按钮，真实目录的展开／收起与可访问性保持不变，中英韩均使用纯标题。
- 修复编译工具栏“选项”“日志”悬停时浅底浅字问题，统一深色悬停／键盘焦点／展开状态；下拉箭头改为文字右侧居中的单一图形，展开方向同步变化，中英韩均不再携带下坠的文字箭头。选项浮层限制在 PDF 面板内，窄窗口也可完整操作。
- “分享”现在直接显示可复制项目链接；首页和账号菜单新增“加入项目”。接收者可打开 LatexStudio 项目链接或粘贴 GitHub HTTPS 地址，明确确认后选择空文件夹下载，打开独立本地副本并向同一个原仓库同步，不自动新建仓库或上传论文。
- 私有权限、邀请接受与 App 安装范围仍独立验证，链接不授予访问权；新增受控启动／第二实例／macOS 链接接收，只预填不自动执行。协议关联仅用于打包安装版，开发／便携入口可手动粘贴。
- 已确认接受邀请后若安装范围查询暂时失败，不再把已接受操作误报为失败或引导重复接受；真正的取消、会话、权限及 HTTP 清理否决仍保留。PDF 预览清理失败也不再阻断已提交工作区的界面接收。
- 新增完整软件界面的简体中文、English、한국어：项目首页、编辑器与搜索、PDF 控件、修改历史、账号、同步、组件、更新、确认弹窗及软件自身固定系统提示均随语言选择切换；账号菜单中选择语言，设置安全保存并跨启动保留。
- 切换语言不翻译或改写论文、源码、文件名、账户/仓库标识及编译器原始日志，也不触发登录、同步或编译；保留正在编辑的草稿、选择与撤销历史。
- GitHub 设备登录改为安全自动续期：访问与续期凭据仅在主进程使用并由操作系统加密保存，重启时重新验证身份；主动退出会清除本机登录。临时断网不删除续期授权，GitHub 撤销授权或续期授权失效仍须重新登录。不使用 App Secret、不关闭 GitHub 的令牌有效期。
- 续期成功后若身份校验暂时断网，30 秒后自动重试校验；不等待下一轮访问令牌到期，也不重复消耗已轮换的续期凭据。
- 从旧版升级后，因旧记录没有续期凭据，需要退出并重新登录一次以取得完整授权；之后不再因短期访问令牌到期反复手动登录。系统安全存储不可用时仍仅本次运行有效，不以明文回退。
- 右上角使用当前登录账号的 GitHub 头像；从固定 GitHub 头像域名按账号ID加载，不发送登录令牌或页面来源。离线、加载失败时显示首字母占位，退出／切换账号立即清理旧头像，不影响写作或同步。
- 修复同步的两处 HTTP 生命周期缺陷：取消时先正确释放响应流；Git 协议响应完整收束后再交给 Git 解析器，避免后续请求误报并发与清理失败。仍保留取消、限时、累计流量上限和真实清理失败保护。
- 已通过真实 GitHub App 私有测试仓库验证首次上传、独立空目录下载、两份副本双向修改、取消后再次同步。仅使用隔离测试文章，不包含个人论文；未冒充另一个人的账号完成邀请测试。
- 同步按钮先保存当前草稿再同步，不再重复弹确认；未登录或未关联时可直接进入所需设置。成功同步后清除已解决的同步错误，其他未解决错误仍保留。
- 参照 Overleaf 官方 History 文档与界面，修改历史改为独立只读模式：左侧文件、中央带行号的源码比较、右侧版本时间线。新增与删除用绿/红色标出，可跳转修改位置、选择同文件的较早版本比较，并返回原编辑草稿。初始记录不把全文标成新增；当前仅回退所选文件，不伪装成整个项目快照。
- 云端操作失败详情完整保留在项目设置中，支持多行、滚动和复制；普通提示也不再以单行省略号截断。不会自动重试建库，403 的具体拒绝原因仍需按实际授权和账号状态核实。
